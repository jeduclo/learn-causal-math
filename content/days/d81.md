## Theory

### Imputation by similar units

Under unconfoundedness given $$X$$ and overlap (Day 42), the ATT is

$$
ATT = E[Y(1) - Y(0) \mid D = 1], \qquad E[Y(0) \mid D = 1, X = x] = E[Y \mid D = 0, X = x] = \mu_0(x).
$$

**Matching** estimates $$\mu_0(X_i)$$ for each treated unit $$i$$ by the outcome of the control (or average of $$M$$ controls) whose covariates are closest:

$$
\widehat{ATT} = \frac{1}{N_1}\sum_{i: D_i = 1}\Big(Y_i - \frac1M\sum_{j \in \mathcal J_M(i)}Y_j\Big).
$$

For the ATE, also match each control to treated units.

### Choices

- **Distance:** Euclidean on standardised covariates, or **Mahalanobis** $$d(x, x') = \sqrt{(x - x')^\top\mathbf S^{-1}(x - x')}$$; or the estimated propensity score (Day 82).
- **With or without replacement:** with replacement, a control can serve several treated units (better matches, higher variance); without, matches get worse as good controls run out.
- **Number of matches $$M$$:** more matches lower variance and raise bias.
- **Caliper:** discard treated units without a control within distance $$c$$. This changes the estimand to the ATT for matched treated units.
- **Exact or coarsened exact matching (CEM):** match exactly on discrete (or coarsened) covariates: equivalent to stratification.

### The bias of matching

Write $$\mu_0(x) = E[Y(0) \mid X = x]$$. For a treated unit matched to control $$j(i)$$,

$$
Y_i - Y_{j(i)} = \underbrace{\big(Y_i - \mu_0(X_i)\big)}_{\text{effect + noise}} + \underbrace{\big(\mu_0(X_i) - \mu_0(X_{j(i)})\big)}_{\text{matching discrepancy}} - \underbrace{\big(Y_{j(i)} - \mu_0(X_{j(i)})\big)}_{\text{noise}}.
$$

The middle term does not vanish when matches are imperfect. With $$k$$ continuous covariates, nearest-neighbour distances shrink only like $$N_0^{-1/k}$$, so with several covariates the bias can dominate the standard error (Abadie and Imbens, 2006).

### Bias correction

Fit a regression $$\hat\mu_0(x)$$ on the controls and adjust each matched difference:

$$
\widehat{ATT}_{bc} = \frac{1}{N_1}\sum_{i: D_i = 1}\Big(Y_i - Y_{j(i)} - \big(\hat\mu_0(X_i) - \hat\mu_0(X_{j(i)})\big)\Big).
$$

This removes the discrepancy term up to the regression's error, combining matching and regression (a doubly robust flavour).

### After matching

Check covariate balance in the matched sample (Day 83); report how many treated units were dropped and how often controls were reused.

### Exercise 3 · Mahalanobis distance

## Part 2 · Proofs

### Exercise 6 · Decomposing the matching estimator

Using the decomposition in the theory, show that $$\widehat{ATT} = \frac{1}{N_1}\sum_{D_i = 1}\big(\tau(X_i) + \text{noise}_i\big) + B_N$$ with $$B_N = \frac{1}{N_1}\sum_{D_i = 1}\big(\mu_0(X_i) - \mu_0(X_{j(i)})\big)$$, where $$\tau(x) = \mu_1(x) - \mu_0(x)$$.

<details><summary>Show solution</summary>

**Step 1.** $$Y_i = \mu_1(X_i) + \varepsilon_i$$ for treated $$i$$, and $$Y_j = \mu_0(X_j) + \varepsilon_j$$ for controls.

**Step 2.** $$Y_i - Y_{j(i)} = \tau(X_i) + \big(\mu_0(X_i) - \mu_0(X_{j(i)})\big) + \varepsilon_i - \varepsilon_{j(i)}$$.

**Step 3.** Average over treated units. $$\blacksquare$$ The first average converges to the ATT; $$B_N$$ is the conditional bias.

</details>

### Exercise 7 · Bias correction with linear μ₀

If $$\mu_0(x) = a + \mathbf b^\top x$$ and $$\hat\mu_0$$ estimates it consistently, show the bias-corrected estimator removes $$B_N$$ asymptotically.

<details><summary>Show solution</summary>

**Step 1.** $$B_N = \frac{1}{N_1}\sum\mathbf b^\top(X_i - X_{j(i)})$$.

**Step 2.** The correction subtracts $$\frac{1}{N_1}\sum\hat{\mathbf b}^\top(X_i - X_{j(i)})$$.

**Step 3.** The difference is $$(\mathbf b - \hat{\mathbf b})^\top\frac{1}{N_1}\sum(X_i - X_{j(i)})$$, a product of two small terms. $$\blacksquare$$

</details>

### Exercise 8 · Exact matching is stratification

With a discrete covariate taking values $$x_1, \dots, x_K$$ and matching each treated unit to all controls with the same value, show $$\widehat{ATT} = \sum_k\frac{N_{1k}}{N_1}(\bar Y_{1k} - \bar Y_{0k})$$.

<details><summary>Show solution</summary>

**Step 1.** A treated unit in cell $$k$$ has imputed $$\hat Y(0) = \bar Y_{0k}$$.

**Step 2.** Average over the $$N_{1k}$$ treated units in cell $$k$$: $$\bar Y_{1k} - \bar Y_{0k}$$.

**Step 3.** Average across cells with weights $$N_{1k}/N_1$$. $$\blacksquare$$ The weights follow the treated distribution: an ATT.

</details>

### Exercise 9 · Why matching discrepancies shrink slowly

Let controls be spread uniformly over $$[0, 1]^k$$ with density $$N_0$$. Argue that the distance from a point to its nearest control is of order $$N_0^{-1/k}$$.

<details><summary>Show solution</summary>

**Step 1.** A ball of radius $$r$$ has volume proportional to $$r^k$$, so it contains about $$N_0 c\,r^k$$ controls.

**Step 2.** The nearest control is typically at the $$r$$ where this count is about 1: $$r \approx (cN_0)^{-1/k}$$.

**Answer:** with $$k = 1$$, distances fall like $$1/N_0$$; with $$k = 4$$, like $$N_0^{-1/4}$$, slower than the $$N^{-1/2}$$ of sampling noise, so the bias does not vanish relative to the SE. $$\blacksquare$$

</details>

### Exercise 10 · Reused controls and variance

With replacement, let $$K_j$$ be the number of times control $$j$$ is used. Show $$\widehat{ATT} = \bar Y_1 - \frac{1}{N_1}\sum_j K_jY_j$$ and that, with homoskedastic noise $$\sigma^2$$, the control part has variance $$\frac{\sigma^2}{N_1^2}\sum_j K_j^2$$.

<details><summary>Show solution</summary>

**Step 1.** Each matched control contributes once per use: $$\frac{1}{N_1}\sum_i Y_{j(i)} = \frac{1}{N_1}\sum_j K_jY_j$$.

**Step 2.** Given the covariates (hence the $$K_j$$), $$\operatorname{Var}\big(\frac{1}{N_1}\sum_j K_j\varepsilon_j\big) = \frac{\sigma^2}{N_1^2}\sum_j K_j^2$$. $$\blacksquare$$ Heavy reuse (large $$K_j$$) inflates variance.

</details>

## Verify in Python

```python
import numpy as np

# Exercises 1-2
xc, yc = np.array([1, 3, 6, 9.]), np.array([10, 13, 17, 21.])
xt, yt = np.array([2.2, 5, 8.4]), np.array([14, 20, 25.])
j = np.array([np.argmin(np.abs(xc - x)) for x in xt])
b = np.polyfit(xc, yc, 1)[0]
print("NN ATT:", round((yt - yc[j]).mean(), 3), " slope:", round(b, 3), " bias-corrected:", round((yt - yc[j] - b * (xt - xc[j])).mean(), 3))
print("CEM:", .3 * 2 + .5 * 3, " naive:", round((360 + 900 + 180) / 100 - (700 + 300 + 90) / 100, 2))

# Exercise 11: a Lalonde-style simulation
rng = np.random.default_rng(81)
def draw(n1=300, n0=6000):
    age = np.r_[rng.normal(25, 5, n1), rng.normal(35, 9, n0)]
    edu = np.r_[rng.normal(10, 1.5, n1), rng.normal(12, 2.5, n0)]
    pre = np.r_[rng.gamma(2, 1500, n1), rng.gamma(4, 3500, n0)]
    D = np.r_[np.ones(n1), np.zeros(n0)].astype(bool)
    y0 = 2000 + 120 * age + 500 * edu + 0.6 * pre + rng.normal(0, 2000, n1 + n0)
    return np.column_stack([age, edu, pre]), D, y0 + 1800 * D
X, D, Y = draw()
Z = (X - X.mean(0)) / X.std(0)
Xt, Xc, Yt, Yc = Z[D], Z[~D], Y[D], Y[~D]
j = np.array([np.argmin(((Xc - x) ** 2).sum(1)) for x in Xt])
beta = np.linalg.lstsq(np.column_stack([np.ones(len(Xc)), Xc]), Yc, rcond=None)[0][1:]
nn = (Yt - Yc[j]).mean(); bc = (Yt - Yc[j] - (Xt - Xc[j]) @ beta).mean()
print(f"naive {Y[D].mean() - Y[~D].mean():,.0f}  NN matching {nn:,.0f}  bias-corrected {bc:,.0f}  (truth 1,800)")
print("controls used:", len(set(j)), "of", len(j), "matches; max reuse", np.bincount(j).max())
```

## Key takeaways

- Matching imputes missing potential outcomes with similar units; with replacement it trades bias for variance, calipers change the estimand.
- Imperfect matches leave a bias that shrinks slowly with several continuous covariates.
- Regression bias correction removes it; always report balance, dropped units and control reuse.
