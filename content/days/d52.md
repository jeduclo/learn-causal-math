## Theory

### Back-door paths

A **back-door path** from $$X$$ to $$Y$$ is a path that starts with an arrow **into** $$X$$: $$X \leftarrow \cdots Y$$. Directed paths $$X \to \cdots \to Y$$ carry the effect; back-door paths carry confounding.

### The criterion

A set of variables $$\mathbf Z$$ satisfies the **back-door criterion** relative to $$(X, Y)$$ if

1. no node in $$\mathbf Z$$ is a descendant of $$X$$, and
2. $$\mathbf Z$$ blocks every back-door path from $$X$$ to $$Y$$ (in the sense of d-separation).

### The back-door adjustment formula

If $$\mathbf Z$$ satisfies the criterion, the causal effect is identified:

$$
P(y \mid \operatorname{do}(x)) = \sum_{\mathbf z} P(y \mid x, \mathbf z)\,P(\mathbf z).
$$

Equivalently, in weighting form,

$$
P(y \mid \operatorname{do}(x)) = \sum_{\mathbf z} \frac{P(x, y, \mathbf z)}{P(x \mid \mathbf z)},
$$

which is IPW (Day 44) with propensity $$P(x \mid \mathbf z)$$.

### Why the two conditions?

- Condition 2 removes all non-causal association.
- Condition 1 keeps the causal paths intact: conditioning on a mediator would block part of the effect; conditioning on a descendant of $$X$$ that is also affected by $$Y$$'s causes could open new paths.

### Link to potential outcomes

In SCM terms, $$\mathbf Z$$ satisfying the back-door criterion implies **conditional ignorability**, $$Y(x) \perp\!\!\!\perp X \mid \mathbf Z$$ (generalising Day 51, Exercise 9). The criterion is a way to *check* Phase 3's unconfoundedness assumption from a graph, and to choose which $$X$$ variables to include.

### Several valid sets

There may be many admissible sets, or none among the observed variables. The parents of $$X$$ always qualify if they are observed. Different admissible sets give the same estimand but different precision (Day 53).

### Linear models

If $$E[Y \mid x, \mathbf z]$$ is linear, $$E[Y \mid x, \mathbf z] = a + bx + \mathbf c^\top\mathbf z$$, then by the adjustment formula $$E[Y \mid \operatorname{do}(x)] = a + bx + \mathbf c^\top E[\mathbf Z]$$: the regression coefficient $$b$$ is the causal effect when $$\mathbf Z$$ is admissible.

## Part 1 · Warm-up

Exercises 1–3 and 5 use this DAG: $$Z_1 \to Z_3 \leftarrow Z_2$$, $$Z_1 \to X$$, $$Z_2 \to Y$$, $$Z_3 \to X$$, $$Z_3 \to Y$$, $$X \to W \to Y$$.

### Exercise 1 · Find the back-door paths

List every back-door path from $$X$$ to $$Y$$ and say which are open given no conditioning.

<details><summary>Show solution</summary>

**Step 1.** $$X \leftarrow Z_3 \to Y$$: fork at $$Z_3$$: open.

**Step 2.** $$X \leftarrow Z_1 \to Z_3 \to Y$$: fork at $$Z_1$$, chain at $$Z_3$$: open.

**Step 3.** $$X \leftarrow Z_3 \leftarrow Z_2 \to Y$$: chain at $$Z_3$$, fork at $$Z_2$$: open.

**Step 4.** $$X \leftarrow Z_1 \to Z_3 \leftarrow Z_2 \to Y$$: collider at $$Z_3$$: blocked.

**Answer:** four back-door paths, three open.

</details>

### Exercise 2 · Is $$\{Z_3\}$$ enough?

Does $$\{Z_3\}$$ satisfy the back-door criterion?

<details><summary>Show solution</summary>

**Step 1.** $$Z_3$$ blocks the first three paths (it is a fork or chain middle on each).

**Step 2.** But $$Z_3$$ is the collider on the fourth path; conditioning on it opens $$X \leftarrow Z_1 \to Z_3 \leftarrow Z_2 \to Y$$.

**Answer:** no. $$Z_3$$ is both a confounder and a collider.

</details>

### Exercise 3 · All minimal admissible sets

Find every minimal set (no proper subset admissible) among $$\{Z_1, Z_2, Z_3\}$$.

<details><summary>Show solution</summary>

**Step 1.** $$Z_3$$ must be included: otherwise $$X \leftarrow Z_3 \to Y$$ stays open.

**Step 2.** With $$Z_3$$ included, the fourth path is open unless $$Z_1$$ or $$Z_2$$ is also conditioned (each is a fork on it).

**Step 3.** $$\{Z_1, Z_3\}$$: blocks paths 1, 2 (at $$Z_1$$ or $$Z_3$$), 3 (at $$Z_3$$) and 4 (at $$Z_1$$). Admissible.

**Step 4.** $$\{Z_2, Z_3\}$$: blocks paths 1, 2 and 3 at $$Z_3$$, path 4 at $$Z_2$$. Admissible.

**Answer:** $$\{Z_1, Z_3\}$$ and $$\{Z_2, Z_3\}$$ (and their superset $$\{Z_1, Z_2, Z_3\}$$).

</details>

### Exercise 4 · A one-variable adjustment

$$Z$$ is binary with $$P(Z = 1) = 0.3$$ and satisfies the back-door criterion. $$E[Y \mid X = 1, Z = 1] = 10$$, $$E[Y \mid X = 1, Z = 0] = 6$$, $$E[Y \mid X = 0, Z = 1] = 8$$, $$E[Y \mid X = 0, Z = 0] = 5$$. Compute the average causal effect.

<details><summary>Show solution</summary>

**Step 1.** $$E[Y \mid \operatorname{do}(X = 1)] = 0.3(10) + 0.7(6) = 3 + 4.2 = 7.2$$.

**Step 2.** $$E[Y \mid \operatorname{do}(X = 0)] = 0.3(8) + 0.7(5) = 2.4 + 3.5 = 5.9$$.

**Answer:** $$7.2 - 5.9 = 1.3$$.

</details>

### Exercise 5 · Adding $$W$$

Is $$\{Z_1, Z_3, W\}$$ admissible? What does adjusting for it estimate?

<details><summary>Show solution</summary>

**Step 1.** $$W$$ is a descendant of $$X$$, so condition 1 fails.

**Step 2.** $$W$$ is the middle of the only causal path $$X \to W \to Y$$; conditioning on it blocks the effect.

**Answer:** not admissible; the adjusted contrast is 0 in population (no direct effect remains), however large the true effect.

</details>

## Part 2 · Proofs

### Exercise 6 · Deriving the adjustment formula

Assume $$\mathbf Z$$ satisfies the back-door criterion. Prove $$P(y \mid \operatorname{do}(x)) = \sum_{\mathbf z} P(y \mid x, \mathbf z)P(\mathbf z)$$, using two facts: (a) interventions do not change the distribution of non-descendants of $$X$$ (Day 51), and (b) if $$\mathbf Z$$ blocks all back-door paths, then $$P(y \mid \operatorname{do}(x), \mathbf z) = P(y \mid x, \mathbf z)$$ (proved formally on Day 55).

<details><summary>Show solution</summary>

**Step 1.** Law of total probability in the intervened model: $$P(y \mid \operatorname{do}(x)) = \sum_{\mathbf z} P(y \mid \operatorname{do}(x), \mathbf z)\,P(\mathbf z \mid \operatorname{do}(x))$$.

**Step 2.** $$\mathbf Z$$ contains no descendant of $$X$$ (condition 1), so by (a) $$P(\mathbf z \mid \operatorname{do}(x)) = P(\mathbf z)$$.

**Step 3.** By (b), $$P(y \mid \operatorname{do}(x), \mathbf z) = P(y \mid x, \mathbf z)$$: once $$\mathbf Z$$ blocks the back-door paths, the only remaining association between $$X$$ and $$Y$$ is causal, so observing $$x$$ and setting $$x$$ are the same.

**Step 4.** Substitute. $$\blacksquare$$

</details>

### Exercise 7 · Parents are admissible

Prove that $$\operatorname{pa}(X)$$ satisfies the back-door criterion (assuming $$Y \notin \operatorname{pa}(X)$$).

<details><summary>Show solution</summary>

**Step 1.** Condition 1: a parent of $$X$$ cannot be a descendant of $$X$$ (that would create a cycle).

**Step 2.** Condition 2: every back-door path starts $$X \leftarrow P$$ with $$P \in \operatorname{pa}(X)$$.

**Step 3.** At $$P$$ the path continues out of $$P$$ ($$P \to X$$ points away), so $$P$$ is a chain or fork middle, not a collider.

**Step 4.** $$P$$ is conditioned, so the path is blocked. $$\blacksquare$$

</details>

### Exercise 8 · The weighting form

Prove $$\sum_{\mathbf z} P(y \mid x, \mathbf z)P(\mathbf z) = \sum_{\mathbf z} P(x, y, \mathbf z)/P(x \mid \mathbf z)$$.

<details><summary>Show solution</summary>

**Step 1.** $$P(x, y, \mathbf z) = P(y \mid x, \mathbf z)P(x \mid \mathbf z)P(\mathbf z)$$.

**Step 2.** Divide by $$P(x \mid \mathbf z)$$ (positive by overlap): $$P(x, y, \mathbf z)/P(x \mid \mathbf z) = P(y \mid x, \mathbf z)P(\mathbf z)$$.

**Step 3.** Sum over $$\mathbf z$$. $$\blacksquare$$

</details>

### Exercise 9 · Regression coefficients under linearity

Suppose $$\mathbf Z$$ is admissible and $$E[Y \mid x, \mathbf z] = a + bx + \mathbf c^\top\mathbf z$$. Prove $$E[Y \mid \operatorname{do}(x + 1)] - E[Y \mid \operatorname{do}(x)] = b$$.

<details><summary>Show solution</summary>

**Step 1.** Take expectations in the adjustment formula: $$E[Y \mid \operatorname{do}(x)] = \sum_{\mathbf z} E[Y \mid x, \mathbf z]P(\mathbf z) = E_{\mathbf Z}[a + bx + \mathbf c^\top\mathbf Z]$$.

**Step 2.** $$= a + bx + \mathbf c^\top E[\mathbf Z]$$.

**Step 3.** The difference between $$x + 1$$ and $$x$$ is $$b$$. $$\blacksquare$$

</details>

### Exercise 10 · Why descendants are excluded

In the chain $$X \to M \to Y$$ with $$M := aX + U_M$$ and $$Y := bM + U_Y$$, there are no back-door paths, so $$\{M\}$$ blocks all of them. Show that "adjusting" for $$M$$ gives the wrong answer.

<details><summary>Show solution</summary>

**Step 1.** True effect: $$E[Y \mid \operatorname{do}(x)] = abx$$, slope $$ab$$.

**Step 2.** $$E[Y \mid x, m] = bm$$ (given $$M$$, $$X$$ adds nothing: chain).

**Step 3.** "Adjusted" formula: $$\sum_m E[Y \mid x, m]P(m) = bE[M]$$, which does not depend on $$x$$: slope 0.

**Answer:** condition 1 is necessary in general; conditioning on a mediator removes the effect it carries. $$\blacksquare$$

</details>

## Part 3 · Applied

### Exercise 11 · Returns to schooling, revisited

In Day 46's DAG ($$F \to A$$, $$F \to S$$, $$A \to S$$, $$A \to W$$, $$S \to O$$, $$S \to W$$, $$O \to W$$), which sets identify the effect of schooling $$S$$ on wages $$W$$? What if ability $$A$$ is unobserved?

<details><summary>Show solution</summary>

**Step 1.** Back-door paths: $$S \leftarrow A \to W$$ and $$S \leftarrow F \to A \to W$$.

**Step 2.** $$\{A\}$$ blocks both (fork or chain middle on each), and $$A$$ is not a descendant of $$S$$: admissible. So is $$\{A, F\}$$.

**Step 3.** $$\{F\}$$ blocks the second but not the first path: not admissible. Occupation $$O$$ is a descendant: never include it.

**Answer:** you must observe ability. Without it no back-door set exists among $$\{F, O\}$$, and other strategies are needed (instruments, Phase 5; or bounds, Day 79).

</details>

### Exercise 12 · A training programme with a sign reversal

Half the jobseekers were previously employed ($$Z = 1$$). Caseworkers send 30% of previously employed and 70% of others to training $$T$$. Employment rates $$P(E = 1 \mid T, Z)$$: previously employed 0.60 untrained, 0.70 trained; others 0.20 untrained, 0.35 trained. $$Z$$ is the only confounder. Compute the naive and adjusted effects.

<details><summary>Show solution</summary>

**Step 1.** $$P(T = 1) = 0.5(0.3) + 0.5(0.7) = 0.5$$.

**Step 2.** Naive, trained: $$\dfrac{0.5(0.3)(0.70) + 0.5(0.7)(0.35)}{0.5} = \dfrac{0.105 + 0.1225}{0.5} = 0.455$$.

**Step 3.** Naive, untrained: $$\dfrac{0.5(0.7)(0.60) + 0.5(0.3)(0.20)}{0.5} = \dfrac{0.21 + 0.03}{0.5} = 0.480$$.

**Step 4.** Adjusted: $$P(E \mid \operatorname{do}(T = 1)) = 0.5(0.70) + 0.5(0.35) = 0.525$$ and $$P(E \mid \operatorname{do}(T = 0)) = 0.5(0.60) + 0.5(0.20) = 0.40$$.

**Answer:** naive $$-2.5$$ points; adjusted $$+12.5$$ points. Training helps, but caseworkers send those with worse prospects.

</details>

### Exercise 13 · Breastfeeding and child health

A DAG: mother's education $$E \to$$ income $$I$$, $$E \to$$ breastfeeding $$B$$, $$I \to B$$, $$I \to$$ child health $$H$$, $$B \to$$ infections $$N \to H$$, and $$B \to$$ clinic visits $$C \leftarrow H$$. Which minimal set identifies the effect of breastfeeding on child health? Which candidate controls must be excluded, and why?

<details><summary>Show solution</summary>

**Step 1.** Back-door paths from $$B$$: $$B \leftarrow I \to H$$ and $$B \leftarrow E \to I \to H$$.

**Step 2.** $$\{I\}$$ blocks both (fork on the first, chain on the second): minimal admissible set. $$\{E, I\}$$ is also admissible; $$\{E\}$$ alone leaves $$B \leftarrow I \to H$$ open.

**Step 3.** Exclude infections $$N$$: a mediator (descendant of $$B$$) on the causal path.

**Step 4.** Exclude clinic visits $$C$$: a descendant of $$B$$ and a collider ($$B \to C \leftarrow H$$); conditioning opens a non-causal path.

**Answer:** adjust for income (optionally education); never for infections or clinic visits.

</details>

### Exercise 14 · Over-controlling a wage regression

In a simulated programme (code below), prior earnings $$P$$ confound training $$T$$ and later earnings $$Y$$; training raises job tenure $$J$$, which raises earnings. True total effect of training: 1.0 ($1,000), of which 0.4 runs through tenure. What do regressions of $$Y$$ on $$T$$ with controls $$\varnothing$$, $$\{P\}$$ and $$\{P, J\}$$ estimate?

<details><summary>Show solution</summary>

**Step 1.** $$\varnothing$$: the back-door path $$T \leftarrow P \to Y$$ is open: badly biased (the code finds about 4.4).

**Step 2.** $$\{P\}$$: admissible: about 1.0, the total effect.

**Step 3.** $$\{P, J\}$$: tenure is a descendant (mediator): the coefficient drops to about 0.6, the effect not running through tenure.

**Answer:** only $$\{P\}$$ answers "what does training do to earnings?". The "control for everything" regression answers a different question, and only if tenure is itself unconfounded (Day 58).

</details>

### Exercise 15 · Hospital report cards

A regulator compares 30-day mortality across hospitals. Candidate adjustment variables: patient severity at admission, age, insurance type, length of stay, and severity at discharge. Draw the relevant DAG fragment and choose the adjustment set for "the effect of being treated at hospital $$H$$".

<details><summary>Show solution</summary>

**Step 1.** Pre-treatment (non-descendants of hospital choice): admission severity, age, insurance. They affect which hospital patients use and their mortality: back-door paths through them must be blocked.

**Step 2.** Length of stay and discharge severity are affected by the hospital (descendants), often mediators of quality.

**Step 3.** Adjusting for discharge severity would credit a hospital for patients it made sicker; length of stay is also affected by deaths themselves.

**Answer:** adjust for admission severity, age and insurance; exclude length of stay and discharge severity. If unmeasured severity remains, hospital comparisons stay confounded, and a sensitivity analysis (Day 95) is needed.

</details>

## Verify in Python

```python
import itertools
import numpy as np
import networkx as nx

dsep = getattr(nx, "is_d_separator", None) or nx.d_separated   # name changed in networkx 3.3

def backdoor_ok(G, x, y, Z):
    """Back-door criterion: no descendant of x, and Z d-separates x and y once x's outgoing edges are removed."""
    if Z & nx.descendants(G, x):
        return False
    H = G.copy(); H.remove_edges_from(list(G.out_edges(x)))
    return dsep(H, {x}, {y}, set(Z))

G = nx.DiGraph([("Z1", "Z3"), ("Z2", "Z3"), ("Z1", "X"), ("Z2", "Y"), ("Z3", "X"), ("Z3", "Y"), ("X", "W"), ("W", "Y")])
cands = ["Z1", "Z2", "Z3", "W"]
valid = [set(c) for k in range(5) for c in itertools.combinations(cands, k) if backdoor_ok(G, "X", "Y", set(c))]
print("admissible sets:", [sorted(v) for v in valid])

# Exercise 12: sign reversal
pT = {1: .3, 0: .7}; pE = {(1, 0): .60, (1, 1): .70, (0, 0): .20, (0, 1): .35}     # key (z, t)
naive = {t: sum(.5 * (pT[z] if t else 1 - pT[z]) * pE[z, t] for z in (0, 1)) / .5 for t in (0, 1)}
adj = {t: sum(.5 * pE[z, t] for z in (0, 1)) for t in (0, 1)}
print("naive:", round(naive[1] - naive[0], 4), " adjusted:", round(adj[1] - adj[0], 4))

# Exercise 14: over-control
rng = np.random.default_rng(52); n = 200_000
P = rng.normal(size=n)
T = (P + rng.normal(size=n) > 0).astype(float)
J = 2 * T + rng.normal(size=n)
Y = 0.6 * T + 0.2 * J + 3 * P + rng.normal(size=n)          # total effect 0.6 + 0.2*2 = 1.0
for name, cols in [("none", []), ("P", [P]), ("P, J", [P, J])]:
    X = np.column_stack([np.ones(n), T] + cols)
    print(f"controls {name:5s}: coefficient on T = {np.linalg.lstsq(X, Y, rcond=None)[0][1]:.3f}")
```

## Key takeaways

- Back-door paths start with an arrow into the treatment; they carry confounding.
- A set is admissible if it blocks them all and contains no descendant of the treatment; then $$P(y \mid \operatorname{do}(x)) = \sum_{\mathbf z} P(y \mid x, \mathbf z)P(\mathbf z)$$.
- A variable can be both a confounder and a collider; the criterion, not intuition, decides what to add.
