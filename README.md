# Beginner to Ninja: Math for Causal Inference — course site

A Next.js site for the 100-day math bootcamp (For Economists · Site Created by Jean Alegue, PhD).
Days 1–15 (Phase 1: Probability & Statistical Inference) are published; Days 16–100 are listed in the
syllabus and switch on automatically when you add their files.

Every day page has a video slot, learning outcomes, a 2-hour session plan, the theory block, 15 exercises
with click-to-show solutions (warm-up 1–5, proofs 6–10, applied 11–15), a "Verify in Python" section, a
downloadable **Colab notebook**, the day's **simulator**, and a "Mark day complete" button. The
**Simulation Lab** tab collects all simulators. Progress and the dark/light choice are stored in each
visitor's browser. The site is fully static: no database, no environment variables.
